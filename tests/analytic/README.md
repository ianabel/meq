
This directory contains functionality for testing the algorithm with a selection of known analytic solutions.
These tests use various hard-coded values. Thus, this is not a complete test. The examples in the 'examples/' directory 
include reference output files given a configuration file. 

This code is not compiled into the main MEQ program, as these are very particular choices for the profiles that do not correspond
to physical profiles. In addition, several of these are tests with prescribed boundary conditions on a plyhedral domain. This is not a
useful operating mode for the general code.
